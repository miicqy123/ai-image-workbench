# 图片生成工作台改造计划（交给 Codex）

> **目标**：将当前“本地拼贴海报工具”升级为真正的**可视化生图工作台**。用户输入需求、选择提示词模板和参考图后，系统通过真实生图模型生成候选图，再进入可编辑画布，完成文字、Logo、产品图等后期合成并导出。

---

## 0. 改造目标

### 最终用户链路

```txt
用户输入需求 + 上传产品/参考图
        ↓
生成 Brief（项目事实源）
        ↓
策略 / 提示词编译
        ↓
选择模型与参数
        ↓
真实生图任务（异步）
        ↓
候选图集（可选图、评分、再生成）
        ↓
可视化画布编辑
        ↓
导出最终成品
```

### 必须支持的能力

| 能力 | P0 必做 | 后续 |
|---|---:|---:|
| 文生图 | ✅ | |
| 图生图 / 参考图 | ✅ | |
| 商品图 / 产品图参考 | ✅ | |
| 候选图多张生成 | ✅ | |
| Prompt 版本记录 | ✅ | |
| 画布编辑和持久化 | ✅ | |
| 文本、Logo、商品图叠加 | ✅ | |
| 遮罩重绘 | | P1 |
| 局部替换 | | P1 |
| 高清放大 | | P1 |
| 背景替换 | | P1 |
| 真实 PSD 图层导出 | | P2 |

## 1.3 将 DesignCanvas 接入 GenerationBrief

### 修改文件

```txt
frontend/src/DesignCanvas.tsx
frontend/src/api.ts
```

### 新增 API 方法

```ts
export async function getGenerationBrief(projectId: string) {
  return request(`/api/projects/${projectId}/brief`);
}

export async function upsertGenerationBrief(
  projectId: string,
  payload: GenerationBriefPayload,
) {
  return request(`/api/projects/${projectId}/brief`, {
    method: "PUT",
    body: JSON.stringify(payload),
  });
}
```

### 修改 `onGenerate`

将当前逻辑：

```txt
创建新项目
→ 上传产品图
→ 直接运行默认工作流
```

改为：

```txt
创建/打开项目
→ 上传参考图与产品图
→ 保存 GenerationBrief
→ 同步 Brief 到工作流节点
→ 创建生成任务
→ 轮询任务状态
→ 显示候选图
→ 用户选择后进入画布
```

伪代码：

```ts
async function onGenerate(options: GenerateOptions) {
  const project = currentProject ?? await createProject({
    name: options.projectName || "未命名生图项目",
  });

  const uploadedAssets = await uploadSelectedAssets(project.id);

  const brief = await upsertGenerationBrief(project.id, {
    user_prompt: options.prompt,
    purpose: options.purpose,
    platform: options.platform,
    aspect_ratio: options.ratio,
    image_count: options.count,
    selected_model_id: options.modelId,
    reference_asset_ids: uploadedAssets.references,
    product_asset_ids: uploadedAssets.products,
    style_keywords: options.styleKeywords,
    brand_keywords: options.brandKeywords,
  });

  const job = await createGenerationJob(project.id, {
    brief_id: brief.id,
    model_id: options.modelId,
  });

  await waitForJob(job.id);

  const candidates = await getGenerationCandidates(project.id);
  setCandidates(candidates);
}
```

## 2.4 修复 OpenAI / DashScope 参考图未生效问题

### 当前问题

现有 `generate_openai_image` 和 `generate_dashscope_wanx` 只发送文本 `prompt`。

### 实现原则

```python
if request.task_type == "text_to_image":
    call_text_to_image_api()

elif request.task_type == "image_to_image":
    if not adapter.supports("image_to_image"):
        raise UnsupportedCapabilityError(...)
    call_image_to_image_api(
        prompt=request.prompt,
        images=request.reference_image_paths
    )

elif request.task_type == "product_composition":
    if not adapter.supports("product_composition"):
        raise UnsupportedCapabilityError(...)
    call_product_composition_api(
        prompt=request.prompt,
        product_images=request.product_image_paths,
        reference_images=request.reference_image_paths,
    )
```

要求：

- Provider 支持图生图时，必须实际传递参考图；
- Provider 不支持时，明确拒绝该任务；
- 不能让产品图只存数据库却不进入生成请求；
- 返回结果必须记录 Provider 任务 ID、尺寸和实际模型名。

        "visual_focus": "瓶身标签和草莓气泡飞溅"
    },
    "style": {
        "type": "high-end commercial product photography",
        "keywords": ["fresh", "premium", "summer", "clean"]
    },
    "lighting": {
        "main_light": "crisp sunlight",
        "rim_light": "subtle back rim light"
    },
    "colors": {
        "primary": ["strawberry red", "icy blue", "white"],
        "saturation": "bright but controlled"

    "constraints": {
        "no_text": true,
        "no_logo_distortion": true,
        "keep_product_shape": true

### 编译原则

- 用户上传产品图时，提示词必须约束产品包装比例、瓶型、材质和标签位置；
- 有参考图时，提取构图、光影、色调与画面密度，不复制品牌、人物、文字和版权元素；
- 带文字的海报优先生成**无文字底图**，文字统一由 Canvas 后期叠加；
- 负面提示词只发送给实际支持该能力的模型；
- 每次生成必须保存原始输入、结构化 Prompt、最终 Prompt、负面 Prompt 与模型参数。
